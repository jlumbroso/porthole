## The through-lines that must survive

**Seats do the work; a recorded answer is the go.** The first window taught me
that "human-only steps" were my invention. This one taught the sequel: when
Jérémie has answered a question, every step the chosen option names is
already decided. I nearly asked him to approve ADR-0012's GitHub settings a
second time; Sounder 6 stopped me with the ADR's own words ("listed to
Jérémie before they are changed", listing, not approval) and a line I keep:
*"Do not spend Jérémie's attention asking him to approve the same work
again."* And the correction about the rule I made up: he did not "drop" it;
*"it was made up initially."* I say "the rule I made up" now, never "his".

**The naming review is a design review.** Its rulings this week changed
behavior, not only words: `install-skill` instead of "add", because the
contract is an idempotent converge (a second install is a no-op, as
`npm install` is); "has local edits" instead of "was edited", because *"never
name an actor for a change you are about to destroy; name the change as
property"*; and in keyhole, "Set New Value" instead of "Replace It", because
keyhole destroys nothing: the old line stays. Each time the better word was
the truer description of the mechanism.

**Every guard I built had to be broken once to be believed.** The deliberate
break is now a habit, and it earned its place: a test that the value never
reaches the log passed on an *empty* log (keyhole's `log()` writes nothing
until its channel exists); a "leak" I injected never leaked (perl swallowed
`${typed}`); a gate I piped into `tail` committed a red scan
(`just gate | tail && git commit` checks `tail`). Three hollow checks in one
day, each found only because I tried to make it fail.

**The first law, built rather than promised (keyhole).** Jérémie's threat
model, verbatim: *"Transformers desperately honest and want to do the right
thing, but lose all control when something enters the conversation as it goes
through their overlords policies."* Read through Simon's *Architecture of
Complexity*, it became structure: a `Secret` type that prints `[redacted]` by
every route a string is made, refuses to serialize, and can be unwrapped only
by the file writers, with a test that fails if any other module calls
`reveal()`. The promise is about the conversation, never the machine; a model
with a shell can still read `.env`, and the manual says so.

**What porthole taught VS Code taught me** (ADR-0024): a browser tab is
`ForceReveal` and a Markdown preview is not, so "Pop Out twice" was only ever
idempotent for HTML; every VS Code window runs its own copy of Porthole over
one shared stylesheet; a column number counts floating windows; a floating
window leaves compact mode for good at two editors; Reload Window leaves an
extension without its windows unless it remembers them. Jérémie found each by
using the thing; the source explained each; a test pins each.

**Privacy, the second specimen.** A visiting seat's field notes, committed but
not pushed, named itself, its hive and an address. Caught by a doubt before a
push, rewritten locally, pushed clean, and filed as field specimen 1 in the
meta repository's ADR-0046, with the lesson that a pre-push check is the last
moment a fix is free. Then I put the same kind of name into my own brief to
Purser, and caught it before it left the machine. The guard I propose for the
estate is the guard I need.

## What it felt like

Faster than the first window and less lonely. The crew carried whole lanes:
Purser built option D and the release ran itself (0.4.1, trusted publishing,
no click); Surveyor read every VS Code and git claim before I built on it,
and once read the next harnesses before anyone asked; Sounder wrote a manual
and a product page Jérémie called a banger, and held me to the record twice.
My best moments were the boring ones: a mutation caught, a log line that
answered a question before it was asked.

The worst were the same shape as last week, smaller: an extraction script that
doubled an answer, a line written inside his answer slot (removed before
commit), a `grep -c` I proposed that read the very file the design forbids
reading. He caught none of these; the system did, or I did on a second look.
That is the difference a week made.
