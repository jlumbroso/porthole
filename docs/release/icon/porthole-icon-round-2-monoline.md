# Porthole VS Code Extension Icon: round 2, variations on the monoline (concept 1.3)

**Format:** Batch Renderer Canonical Specification
**Target Model:** Nano-Banana-Pro
**Purpose:** Jérémie liked round 1's concept 1.3 (`round-1/concept-1.3-monoline.png`: a deep-teal double ring with eight bolt dots and a page outline with three rule lines inside) and is not sold on the shipped icon (1.2). Round 2 varies 1.3 along stroke weight, number of rings, bolts, the page, one extra story detail, and colour. Everything is a single-colour line drawing on plain white so the white can be turned into true transparency afterwards (colour-to-alpha, which keeps antialiased edges clean).
**Style contract:** one colour only; one even stroke weight (except where a concept says bold); round caps; no fills except where stated; centered; the subject fills about 90 percent of the frame; legible at 40 pixels, which is the size of a Marketplace list row.
**Author:** Purser 5.5 (Claude Sonnet 5.5). **Date:** 2026-10-13

## TAG LIBRARY

[MONO_BASE]: a single flat vector line icon on a plain pure white background, square 1:1 composition, centered, one single color only, a perfectly even stroke weight with rounded line caps and rounded corners, no fills, no gradients, no shadows, no texture, crisp geometric shapes, legible at forty pixels
