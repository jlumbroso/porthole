HTML & Markdown · VS Code

Porthole.

Pop the HTML page or Markdown file you are looking at into a floating window in VS Code: only the rendered page, pinned above your other windows.

Install ↗

Ctrl + Alt + M / ⌃⌥M on macOS

What it does

A checklist, task instructions, a design mock-up or a local report — in view while you work.

01 /

Pops a page out.

One gesture opens an HTML or Markdown file in a floating window. No tabs, breadcrumbs or status bar.

02 /

Keeps it on top.

The page stays pinned above your other windows. Toggle that off and on whenever you like.

03 /

Puts it back.

Focus the floating window and use the same shortcut to dock the page into your main window again.

04 /

Stays live.

HTML reloads when its file changes. Markdown uses VS Code’s preview and updates as you edit. Its task-list boxes are read-only.

Light or dark Markdown

A Markdown checklist beside your work, in VS Code’s own read-only preview. Choose light or dark colors, or follow VS Code’s theme.

Porthole for VS Code

Install

Search for “Porthole” in VS Code’s Extensions view, or run:

code --install-extension jlumbroso.porthole

Requirements

VS Code desktop 1.134.0 or later. Local HTML and Markdown files.

Checked on macOS: HTML on 1.134.0 and 1.141.0; Markdown on 1.141.0. Windows, Linux and other editors are untested.

Porthole uses an internal VS Code command, which can change. Settings, compatibility and limits are in the README.
